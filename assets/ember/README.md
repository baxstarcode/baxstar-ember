# Ember steampunk asset pack

Implementation-ready visual system for the responsive Ember OPS and Baxstar Studio React interface.

Start with:

1. `CLAUDE-HANDOFF.md`
2. `manifest.json`
3. `control-map.json`
4. `design-tokens.css`
5. `docs/integration-snippets.md`

The two files in `mockups/` are visual-intent references only. Do not use them as application backgrounds.

Raster implementation assets:

- `raster/skull-arch@2x.png`
- `raster/glass-tank@2x.png`

Everything else is scalable SVG or text configuration.
